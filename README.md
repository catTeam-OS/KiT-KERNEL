# KiT-KERNEL

A simple kernel for my own OS.

## Status

This repository is currently a project scaffold. Kernel source code and build instructions have not been added yet, so there is no build or test command to run.

## Project layout

The repository currently contains the root project files and a `KiT/` directory with placeholder files. GitHub Actions only discovers workflow files under the repository-root `.github/workflows/` directory; the empty workflow placeholder currently under `KiT/.github/workflows/` will not run from this repository.
